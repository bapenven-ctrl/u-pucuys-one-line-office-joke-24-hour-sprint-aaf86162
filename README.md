A program that writes one office joke — the camera stays off, the manager still says thanks, and the empty square gets promoted — to `/output/entry.txt`. The line is 147 characters, one line, UTF-8, no trailing newline. Deterministic: two runs write byte-identical files. No network, no dependencies outside this repository.

## Run it

```sh
python3 main.py
```
